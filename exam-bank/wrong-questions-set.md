## 第 5 题

**题目：** 某系统由 4 个相互独立的部件组成，每个部件的可靠度均为 0.9。系统至少需要 3 个部件正常才能工作，则系统可靠度约为：

A．0.9477  
B．0.9720  
C．0.9963  
D．0.9999

**你的答案：** D  
**正确答案：** A

**解析：**

系统要求“至少 3 个正常”，属于表决/组合可靠度模型：

\[
P = C(4,3) \times 0.9^3 \times 0.1 + C(4,4) \times 0.9^4
\]

\[
P = 4 \times 0.729 \times 0.1 + 0.6561 = 0.2916 + 0.6561 = 0.9477
\]

注意区分：

- 至少 1 个正常（全并联）：\(1 - 0.1^4 = 0.9999\)
- 至少 3 个正常：\(0.9477\)

## 第 8 题

**题目：** 在关系数据库规范化中，若关系模式已满足 2NF，并且消除了非主属性对码的传递函数依赖，则至少达到：

A．1NF  
B．2NF  
C．3NF  
D．BCNF

**你的答案：** D  
**正确答案：** C

**解析：**

- 1NF：属性不可再分。
- 2NF：消除非主属性对码的**部分函数依赖**。
- 3NF：在 2NF 基础上，消除非主属性对码的**传递函数依赖**。
- BCNF：进一步消除主属性对码的部分和传递函数依赖。

所以题目描述对应 **3NF**。

## 第 10 题

**题目：** 在 STRIDE 威胁建模中，Tampering（篡改）主要威胁的是：

A．保密性  
B．完整性  
C．可用性  
D．不可抵赖性

**你的答案：** D  
**正确答案：** B

**解析：**

STRIDE 与安全属性对应关系：

| 威胁 | 对应属性 |
|---|---|
| Spoofing 假冒 | 认证 |
| Tampering 篡改 | **完整性** |
| Repudiation 抵赖 | 不可抵赖性 |
| Information disclosure 信息泄露 | 保密性 |
| Denial of service 拒绝服务 | 可用性 |
| Elevation of privilege 提权 | 授权 |

Tampering 对应 **完整性**。

## 第 18 题

**题目：** 在关系代数中，从关系中选出满足指定条件的元组，对应的运算是：

A．投影  
B．连接  
C．除法  
D．选择

**你的答案：** A  
**正确答案：** D

**解析：**

- 选择 σ：按条件选**元组**，即筛选行。
- 投影 π：选**属性列**。
- 连接 ⋈：按条件组合两个关系。
- 除法 ÷：常用于“包含全部”类查询。

“选出满足条件的元组”对应 **选择**。

## 第 19 题

**题目：** 某处理器主频为 2GHz，指令平均执行 4 个时钟周期，则其 MIPS 约为：

A．250  
B．500  
C．800  
D．1000

**你的答案：** A  
**正确答案：** B

**解析：**

\[
MIPS = \frac{主频}{CPI}
\]

2GHz = 2000MHz，CPI = 4：

\[
MIPS = \frac{2000}{4} = 500
\]

所以正确答案是 **B**。

## 第 25 题

**题目：** 某系统由两个子系统串联组成，每个子系统由两个可靠度均为 0.9 的组件并联组成。系统整体可靠度为：

A．0.9801  
B．0.9900  
C．0.8100  
D．0.9999

**你的答案：** C  
**正确答案：** A

**解析：**

每个子系统内部是两个 0.9 组件并联：

\[
R_{子系统} = 1 - (1-0.9)^2 = 1 - 0.01 = 0.99
\]

两个子系统串联：

\[
R_{系统} = 0.99 \times 0.99 = 0.9801
\]

所以正确答案是 **A**。  
0.81 = \(0.9 \times 0.9\)，是把两个组件当成串联计算的结果。

## 第 28 题

**题目：** 在 E-R 图中，菱形通常表示：

A．实体  
B．属性  
C．联系  
D．主键

**你的答案：** D  
**正确答案：** C

**解析：**

E-R 图常见符号：

| 符号 | 含义 |
|---|---|
| 矩形 | 实体 |
| 椭圆 | 属性 |
| 菱形 | 联系 |
| 下划线 | 主键属性 |

所以菱形表示 **联系**。

## 第 45 题

**题目：** 袋中有 5 个白球和 3 个黑球，任取 2 个球，恰好有 1 个黑球的概率是：

A．5/14  
B．3/8  
C．15/28  
D．15/56

**你的答案：** B  
**正确答案：** C

**解析：**

总取法：

\[
C(8,2) = 28
\]

恰好 1 个黑球、1 个白球的取法：

\[
C(3,1) \times C(5,1) = 3 \times 5 = 15
\]

概率：

\[
P = \frac{15}{28}
\]

所以正确答案是 **C**。

## 第 46 题

**题目：** ADL（架构描述语言）主要用于描述：

A．类、对象、方法和继承关系  
B．用例、参与者和业务场景  
C．数据库表、视图和索引  
D．构件、连接件和架构配置

**你的答案：** A  
**正确答案：** D

**解析：**

ADL 用于描述软件架构的三大核心元素：

- 构件 Component
- 连接件 Connector
- 配置 Configuration

A 是面向对象/类图关注的内容；B 是用例建模；C 是数据库设计。

## 第 54 题

**题目：** 关于进程和线程，下列说法正确的是：

A．线程是资源分配的基本单位，进程是 CPU 调度的基本单位  
B．同一进程内的线程完全独立，不共享任何资源  
C．进程是资源分配的基本单位，线程是 CPU 调度的基本单位  
D．一个进程不能包含多个线程

**你的答案：** A  
**正确答案：** C

**解析：**

- 进程：资源分配的基本单位，拥有独立地址空间。
- 线程：CPU 调度的基本单位，同一进程内的线程共享进程资源。
- 选项 A 把两者角色说反了。

## 第 58 题

**题目：** 在关系数据库中，能唯一标识元组且不包含多余属性的属性或属性组称为：

A．候选码  
B．主键  
C．外键  
D．超码

**你的答案：** B  
**正确答案：** A

**解析：**

- 候选码：能唯一标识元组，且不包含多余属性。
- 主键：从候选码中选定一个作为主键。
- 超码：能唯一标识元组，但可能包含多余属性。
- 外键：用于建立与其他关系的参照关系。

题目强调“不包含多余属性”，所以是 **候选码**。

A．白盒测试  
B．黑盒测试

## 第 73 题

**题目：** 英文原文：

> ... circuit breaker and bulkhead to prevent **__(73)__** failures.

A．temporary  
B．random  
C．silent  
D．cascading

**你的答案：** C  
**正确答案：** D

**解析：**

- **cascading failure**：级联故障/雪崩故障。
- 断路器、舱壁隔离用于防止一个依赖故障引发级联失败。

所以选 **cascading**。
